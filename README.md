# 📊 Sales Analytics Dashboard

## Overview

This project is an interactive Sales Analytics Dashboard developed using Power BI to analyze sales performance, revenue trends, customer behavior, product performance, and market-wise insights.

The dashboard helps businesses monitor key performance indicators (KPIs), identify top-performing markets and customers, and make data-driven decisions.

## Business Problem

Businesses generate large volumes of sales data every day. Analyzing this data manually is time-consuming and often fails to reveal important trends and opportunities.

This dashboard was created to:

- Track overall sales performance
- Monitor revenue trends
- Identify top customers
- Analyze top-performing products
- Compare sales across different markets
- Support data-driven business decisions
